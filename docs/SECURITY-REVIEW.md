`inputs_digest` (SHA-256 over the advisory), never the advisory text (`grep -c free_text

`model_rationale` carries a short rationale string labelled `RATIONALE_NOT_AUDIT_RECORD`; escalation
summaries name the card, tier, risk, action and options, not the source email. Production, stated

ledger; free text is readable by the duty supervisor and the card's approver through the operator
identity (S-11's production federation), never by the agent credentials, which hold the digest.
